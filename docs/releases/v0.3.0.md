# REMORA v0.3.0

26 Oktober 2026

Pembaruan dari v0.2.0. Peta partisi, profil, rekor dan rating yang tersimpan dipertahankan saat OTA.

## Suara

- Melodi game over lebih panjang, serta variasi khusus ketika mencetak rekor.
- Efek clear, portal, bonus, makanan, pantulan Pong, damage, konfirmasi, rating tersimpan dan ajakan rating.
- Efek memilih bintang dan peringatan input. Semua mengikuti volume Utama/SFX; musik menu tetap mengikuti slider BGM.
- Firmware memakai antrean nada tanpa penundaan blocking pada alur render LCD.

## Ajakan rating yang tidak mengganggu

- Muncul opsional 2,8 detik setelah game over, setelah pemain sempat membaca hasilnya.
- Perlu minimal tiga game yang benar-benar berakhir. Hasil harus cukup berarti: dua level selesai, skor minimal 600, atau rekor baru dengan setidaknya satu level selesai.
- Minimal enam game over di antara dua ajakan, serta cooldown sepuluh menit dalam sesi penyalaan yang sama.
- Profil bersama boleh mendapat ajakan berulang, termasuk game yang sudah dinilai: normalnya setelah 12 game tambahan dan 30 menit.
- Perubahan rata-rata skor yang konsisten pada game/difficulty sama dapat mempercepat ke enam game tambahan dan sepuluh menit. Perbandingan tiga hasil dengan baseline tiga hasil memerlukan selisih minimal 600 poin serta dua kali lipat; satu hasil menyimpang dan pergantian difficulty tidak cukup.
- Setiap jawaban tetap menjadi catatan Rate terpisah. Skor merupakan petunjuk feedback, bukan identifikasi pemain. Rating manual turut mengatur ulang jeda; XDAXA tidak mendapat ajakan.
- Retry atau keluar sebelum ajakan muncul membatalkan ajakan tertunda. Arsip rating penuh juga menonaktifkan ajakan baru.
- Merah memilih Nanti. Hijau membuka penilaian game terkait. Setelah selesai atau batal, kembali ke hasil game sebelumnya.
- Di Settings profil XDAXA ada RATING PROMPT: OFF/ON, berlaku global untuk semua pemain dan tetap tersimpan setelah penyalaan ulang. Rate Me manual tetap tersedia saat ajakan dinonaktifkan.

## Tampilan

- Judul daftar profil menjadi PLAYER PROFILE.
- Kucing Achievements dipindahkan ke ruang kosong di kiri angka; angka ribuan hingga jutaan tetap terbaca.
- Tema MONO / WHITE / BLACK tersedia bersama Amber dan Ocean, disimpan per profil. Warna sinyal game dan keyswitch tetap bermakna agar permainan bisa diikuti.
- Bar atas halaman sebelum bermain tidak lagi mengulang Ready to Play dan nama game. Judul game utama serta indikator baterai tetap ada.

## OTA

- Manifest harus cocok dengan tag rilis dan aset repo, memiliki hash heksadesimal valid, dan muat di slot OTA sebelum update ditawarkan.
- Transfer metadata maupun firmware harus lengkap. Kegagalan header HTTP dan pengalihan ke HTTP tanpa TLS ditolak.
- Penawaran update lama dibersihkan saat Wi-Fi putus; pemasangan offline ditolak.
- Kode updater asli diuji dengan firmware rilis publik dan simulasi kegagalan jaringan/flash. Uji fisik ESP32-C6 tetap diperlukan.

## Verifikasi dan pemasangan

Simulator, alur rating, kebijakan cooldown, input, profil, audio dan native core diperiksa otomatis. Build firmware memakai ESP-IDF 5.5.2. Perangkat fisik tetap perlu diuji.

Pilih Settings > Network > OTA Update untuk memperbarui. `remora-esp32c6.bin` adalah file OTA; `remora-full.bin` untuk pemasangan awal. Jangan erase flash jika ingin mempertahankan data pemain.
