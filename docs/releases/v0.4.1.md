# REMORA v0.4.1

27 Oktober 2026

- Memperbaiki kegagalan pemeriksaan OTA pada ESP32-C6 ketika framebuffer layar sudah dialokasikan. Dokumen GitHub dan pohon JSON dilepas sebelum membuka koneksi HTTPS manifest, sehingga kedua alokasi besar tidak bertumpuk.
- Buffer C++ kini dilepas sebelum task FreeRTOS dihapus, termasuk saat gagal, cancel, atau versi sudah terbaru. Pemeriksaan berulang tidak meninggalkan buffer respons di heap.
- Menambah regresi yang memastikan alokasi JSON daftar rilis sudah bersih sebelum koneksi manifest dimulai. Verifikasi sertifikat, hash, versi, batas ukuran, partisi nonaktif dan perlindungan userdata tetap berlaku.
- Memuat seluruh perubahan v0.4.0: variasi Light Maze/Snake/Pong, Auto Off default lima menit, dan perbaikan USB/event Wi-Fi.

Peta partisi dan userdata schema tetap sama. Jika firmware lama gagal memeriksa update dengan pesan release/manifest, v0.4.1 dapat dipasang melalui USB satu kali tanpa erase userdata; setelah itu coba OTA kembali.
