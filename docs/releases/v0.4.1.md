# REMORA v0.4.1

27 Oktober 2026

- Pemeriksaan versi memakai HEAD pada tautan resmi GitHub Releases latest, lalu manifest maksimal 4 KB. Daftar rilis JSON besar tidak lagi dimuat pada ESP32-C6. Tag harus berasal dari repo REMORA dan berupa Semantic Version stabil.
- Manifest memakai buffer tetap yang diperiksa sebelum HTTPS; tidak ada pertumbuhan string besar selama TLS aktif. Buffer dilepas sebelum task FreeRTOS dihapus, termasuk saat gagal atau cancel.
- Request buffer aset 4 KB menampung alamat pengalihan GitHub yang panjang dan bertanda tangan. Request pengecekan tag tetap kecil. Transfer berhenti segera setelah pesan HTTP lengkap.
- “Ready to update to x.x.x version” tampil hanya setelah versi lebih baru dan manifest tervalidasi. “Latest firmware” tampil ketika versi terpasang sudah terbaru. Gagal/cancel tidak mengubah status menjadi terbaru.
- Sertifikat HTTPS, tag/versi, board, ukuran, SHA-256, descriptor aplikasi, slot nonaktif dan pemisahan userdata tetap diverifikasi.
- Wi-Fi berhenti otomatis setelah 30 detik tidak digunakan di menu biasa, dua menit tanpa input pada halaman jaringan, atau lima menit tanpa aktivitas pada setup ponsel. Input pada halaman jaringan dan request setup HTTP mengulang timer. Scan, koneksi yang sedang berlangsung dan OTA aktif dilindungi. Mulai game dan standby/mati tetap mematikan radio segera. SSID tersimpan dan data profil tidak dihapus; tawaran OTA lama dibatalkan jika radio berhenti otomatis.
- Perbaikan audio ESP32-C6 mempertahankan sampel 8 kHz dan carrier 80 kHz, tetapi pembaruan duty memakai jalur register singkat. Timer sampel berhenti saat senyap/mute dan output dibuat rendah. Ini mengatasi backlog timer/watchdog yang ditemukan sesudah OTA v0.4.0. Watchdog kini merestart aplikasi yang macet agar rollback bootloader dapat berjalan.
- Memuat seluruh perubahan v0.4.0: variasi Light Maze/Snake/Pong, Auto Off default lima menit, dan perbaikan USB/event Wi-Fi.

Peta partisi dan userdata schema tetap sama. Jika firmware lama gagal memeriksa update dengan pesan release/manifest, v0.4.1 dapat dipasang melalui USB satu kali tanpa erase userdata; setelah itu coba OTA kembali.

Pola tautan latest mengikuti [dokumentasi GitHub](https://docs.github.com/en/repositories/releasing-projects-on-github/linking-to-releases).
