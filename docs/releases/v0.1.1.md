# REMORA v0.1.1 (draft internal)

Perubahan ini digabung ke [v0.2.0](v0.2.0.md). v0.1.1 tidak diterbitkan sebagai firmware OTA.

26 Oktober 2026

Pembaruan dari v0.1.0. Peta partisi dan schema profil tetap sama; OTA mempertahankan profil, rekor dan pengaturan.

- Batal tambah profil dari Settings: merah saat nama kosong, atau tahan merah satu detik; kembali ke daftar tanpa membuat profil/memakai slot. Simulator juga mendukung Escape.
- Simulator mendukung numpad **4 5 6 / 1 2 3** untuk KEY1–6, termasuk Num Lock mati.
- Perbaikan tutorial: klik tombol dan keyboard dapat melanjutkan langkah; kombinasi skip tidak lagi menelan input biasa.
- Tahan **KEY1 + KEY3 / kiri atas + kanan atas dua detik** untuk membuka konfirmasi matikan. Di simulator: **numpad 4 + 6**, atau Q + E.
- **Hijau / KEY6** mengonfirmasi; **merah / KEY4** membatalkan dan kembali ke halaman/permainan semula. Waktu game berhenti saat kombinasi ditahan dan selama konfirmasi.
- Konfirmasi menjalankan animasi mati lalu standby; penyalaan kembali tetap KEY1 + KEY3 dua detik. Sakelar catu S0 tetap terpisah.
- Pintasan KEY4 saja untuk keluar game dua detik tetap tersedia; kombinasi shutdown mempunyai prioritas.
- Firmware dan simulator memakai kombinasi serta konfirmasi mati yang sama.

- Tutorial memakai dialog lebih kecil dengan teks rata tengah, tanpa label MEOW. Hijau melengkapi teks lalu menutup dialog untuk praktik; pesan muncul kembali saat langkah berikutnya. Kucing pendamping juga disembunyikan selama praktik.
- Kontrol Snake: KEY2 naik, KEY5 turun, KEY6 kanan dan KEY4 kiri. Panah keyboard mengikuti arah yang sama; KEY1/KEY3 tidak dipakai untuk gerakan Snake.
- Settings → Network membuka menu terlebih dahulu, tanpa memulai scan. Pilih **SCAN WIFI** untuk memindai jaringan. Pilih SSID; jaringan terkunci membuka password, jaringan terbuka langsung disambungkan. Input nama Wi-Fi manual pada perangkat dihapus. Scan ulang dan kembali ke menu Network tersedia; Phone Setup tetap menjadi pilihan terpisah.
- Pemindaian ESP32 memakai scan Wi-Fi asinkron, mengurutkan hasil berdasarkan sinyal dan menggabungkan SSID duplikat dengan jenis keamanan sama. Simulator menampilkan jaringan contoh dengan label SIMULASI; browser tidak memindai Wi-Fi asli. Pemindaian perangkat memakai driver Wi-Fi ESP32-C6; pengujian hardware tetap diperlukan.

- Pesan penutup tutorial tampil di Home dengan Classic terpilih. Setelah selesai atau skip, pemain tetap berada di Home Classic.

- Teks pendukung, petunjuk tombol, status game dan pengaturan diperbesar dari 7 menjadi 9 piksel, dengan lebar sekitar 20% lebih besar dan batas lebar agar tetap muat. Teks utama dan penanda peta padat tetap memakai ukuran semula.
- Ikon petir tampil di samping indikator baterai pada header saat USB charger terhubung; posisi persen baterai bergeser agar tidak bertumpuk.

- KEY1 + KEY3 dua detik membuka konfirmasi matikan; input navigasi diproses saat tombol dilepas, dan pasangan tombol menahan auto-repeat agar halaman tidak bergeser.
- Preview Snake memakai sprite ular sapi pojok kanan atas, dan Pong memakai sapi pingpong kedua dari kanan pada baris bawah dari sheet pengguna.
- Layar shutdown menempatkan kucing tidur di punggung sapi.

- Persentase baterai pada header memakai teks 11 piksel; ikon baterai menjadi 27 x 15 piksel dengan petir di sebelahnya saat charger terhubung.
- Signal Decoder: KEY1/KEY3 pindah digit, KEY2 tambah, KEY5 kurang, KEY6 OK, KEY4 hapus. Petunjuk pada layar dan shortcut panah mengikuti susunan ini.
- Snake menembus empat sisi layar pada Easy, Normal dan Hard. Expert dan Master tetap memakai dinding mematikan; tabrakan tubuh dan batu tetap berbahaya.
- Paddle Pong dan preview Pong putih solid.

## Pemasangan dan pengujian

Pembaruan OTA memakai `remora-esp32c6.bin`. `remora-full.bin` untuk pemasangan awal. Hindari erase flash agar data pemain tetap tersimpan. Simulator dan native core diperiksa otomatis; build memakai ESP-IDF 5.5.2. Koneksi Wi-Fi, kestabilan LCD dan rangkaian fisik tetap perlu diuji pada perangkat.
