# REMORA v0.4.0

27 Oktober 2026

- Light Maze berganti misi tiap level: cari kunci K untuk membuka gerbang X, panen susu, lalu ekspedisi goal. Kunci dapat berada di cabang, dengan tambahan langkah yang diperhitungkan. Hard/Expert mendapat dua scan peta 1,4 detik; Master satu scan. Easy/Normal tetap langsung bermain tanpa sesi hafalan peta.
- Snake: susu emas memberi 90 poin selama 6,5 detik, lalu kembali menjadi rumput biasa tanpa penalti. Aturan tembus dinding dan kontrol tidak berubah.
- Pong: bidik target susu saat mengembalikan bola untuk 20 poin dan paddle lebih lebar selama lima detik. Bonus tidak bertumpuk, punya jeda 3,5 detik, dan tidak mengubah target kemenangan.
- Panduan dan HUD diperbarui untuk ketiga game tersebut, termasuk simbol kunci/gerbang, sisa susu/langkah/scan dan bonus sementara.
- Settings > Auto Off: nonaktif, 1, 2, 5, 10, 15 atau 30 menit. Default lima menit, disimpan per profil. Profil lama otomatis mendapat default tanpa kehilangan data.
- Input tombol mengulang timer. Tanpa input, animasi shutdown menyimpan data lalu masuk standby. Aktivitas otomatis game/render tidak mengulang timer; membuka kembali perangkat memulai interval baru.
- Auto Off ditunda selama OTA aktif dan selama fase boot, shutdown atau pemberitahuan daya. Setelah OTA selesai, interval dimulai kembali.
- Menghapus konfigurasi konsol lama yang mematikan USB Serial/JTAG.
- Stack task event Wi-Fi/IP dinaikkan menjadi 6144 byte setelah stack overflow ditemukan pada ESP32-C6 fisik.

Uji COM13 berhasil menjalankan core dan renderer tanpa LCD, serta tersambung ke Wi-Fi terbuka. OTA fisik belum berhasil karena jaringan mengarahkan ESP32 ke portal login icpaser.net; image tidak diunduh/diinstal melalui OTA. Isi flash awal board dipulihkan dan diverifikasi identik. Lihat [laporan perangkat](../HARDWARE_TEST_2026-10-27.md).

Peta partisi dan schema userdata tetap sama. Pengujian fisik dilakukan dengan board tanpa layar; kemampuan visual LCD, kalibrasi baterai dan periferal tetap memerlukan pengujian saat dipasang.
