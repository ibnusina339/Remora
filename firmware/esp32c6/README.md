# REMORA ESP32-C6 firmware

ESP-IDF 5.5.2 + LVGL 9.2.2. Native C++ game modules, Rev K2 power policy, SPI DMA, GitHub Releases OTA and four local profiles.

Start with [flashing instructions](../../docs/FLASHING.md). Hardware reference is [Rev K2](../../docs/hardware/REMORA_Schematic_Rev_K2_A4.pdf). Browser simulator: open ../../index.html.

This folder is the current firmware target. Older firmware/src and lvgl-zephyr experiments are not the installable application. Build verification is performed by the GitHub Actions workflow. Physical-board validation is separate.
